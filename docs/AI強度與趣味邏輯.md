# AI 強度與趣味邏輯

本版目標是減少容易被利用的固定決策，並讓玩家有更多翻牌後的判斷、誘敵與反制機會。只修改來源碼與文件；依需求不執行測試、Godot 載入檢查或實機對局，也未重新匯出根目錄 `Puker.exe` 或 `web/` 成品。策略效果與執行相容性尚未驗證，不宣稱勝率已提升。

## 資訊與決策流程

1. `AIObservationQuery` 複製自己的底牌、公共牌、合法動作與公開統計；不傳入對手底牌、牌堆順序或其他 AI 的性格。
2. `estimate_equity` 使用設定中的抽樣數（預設 48），依公開行為對假想對手手牌加權，沿用遊戲評牌規則計算分池權益。
3. `choose` 計算位置、跟注成本、底池賠率、有效剩餘籌碼、SPR、成牌與聽牌，再決定棄牌／過牌／跟注／加注。
4. 下注轉換成本街總額，套用引擎的最小與最大加注限制，再套用策略風險限制。未成功加注時清除詐唬標記與金額。
5. 保存本街最後動作，供下一街判斷主動權；發言在決策之後產生，不影響手牌或輸贏。

## 翻牌前：正常交手，短碼才推進

修正舊程式 50BB 就採推／棄的門檻為 **12BB**。超過 12BB 保留正常開池與防守，弱牌進池仍須符合跟注價格。

| 情境 | 規則 |
| --- | --- |
| 未有人加注 | 起手分數門檻：前位 0.45、中位 0.40、後位 0.33；單挑再放寬 0.04。角色有固定 ±0.025 微調，愛說謊型額外放寬 0.025。 |
| 開池尺寸 | 後位 2.3BB，其他位置 2.7BB；仍受合法最小加注限制。 |
| 面對加注 | 後位門檻 0.43，其他 0.49，加角色微調；成本超過 4BB 或有效籌碼 15% 時門檻增加 0.08，隨近期施壓讀數線性降至 0.02。另按讀數最多降低基礎門檻 0.05。跟注還須滿足賠率安全差。 |
| 小注跟進 | 超過 12BB，跟注成本至多 3BB 且至多有效籌碼 8%；後位或已有至少兩名對手自願進池時分數門檻 0.38，其他 0.43。投機起手且深度至少為成本 20 倍，可走投機牌路徑。使用下節的小注權益門檻。 |
| 再加注 | 起手分數至少 0.82、權益至少 0.56 且高於賠率＋安全差＋0.10；對已辨識的再加注型可放寬至 0.77，但權益至少 0.57。尺寸後位 3 倍、其他 3.5 倍目前總注額。 |
| 12–25BB | 已符合再加注條件時可全下；更深籌碼採正常再加注。 |
| ≤12BB | 未開池時按起手門檻與權益推進；面對加注起手分數至少 0.70，權益須過賠率安全差。分數至少 0.65 且價格合適時也可跟注；免費過牌保留。 |

起手分數沿用對子、點數、同花與連張啟發式，不是百分位範圍表。加注權未開放時，仍可按權益與價格跟注。

### 避免翻牌前只剩兩人

新增公開 `entered_pot` 欄位，只在玩家自願跟注／加注後為真；強制盲注不算自願進池。進池人數只統計尚未棄牌的對手，不將尚未行動者當成已跟注者。

超過 12BB 才使用下列低成本參與路徑，短碼維持原本規則：

- **小注價格**：成本 >0、至多 3BB、且至多有效籌碼 8%。小注權益門檻為 `max(0.12, 底池賠率 + 位置安全差 - 投機折讓)`；後位安全差 0.01，其他 0.02，不再按尚未棄牌人數重複加罰。
- **投機起手**：口袋對子、同花間隔至多 3 點、同花 A，或低張至少 8 的非同花連張。有效籌碼至少為成本 20 倍時，投機折讓為 0.035，其他為 0。這是有限的隱含賠率近似，並不保證未來能贏得額外籌碼。
- **未有人加注**：成本至多 1BB、滿足小注價格與權益、起手分數至少 0.40 或屬投機起手，且分數低於 0.72 時，可選擇 limp／overlimp。未達開池門檻但符合上述條件者直接跟進；已達開池門檻者，未有其他進池者時 45% 改跟進，已有進池者時 80% 改跟進。其餘保留開池選擇。
- **大盲免費看牌**：已有自願進池者，且自身起手分數低於 0.72 時過牌，不用中等牌強行加注清場。
- **面對正常小開池**：符合小注價格、權益與起手範圍即可跟進，不要求同時通過原本較嚴的常規防守門檻。已有人跟注所增加的底池會直接改善價格。

這些規則允許三人以上看翻牌，但不保證每手都有固定人數。大額加注、短碼或低權益仍可讓牌局縮成單挑；也不強迫跟注到攤牌。此調整尚未執行測試或量測多人翻牌比例，匯出成品未更新。

## 翻牌後：成牌、聽牌與主動權

賠率為 `跟注成本 / (目前底池 + 跟注成本)`。安全差為 `0.025 + 0.015 × 額外對手數`，河牌之前且不在最後行動位置再加 0.015。

對目前最高下注者的近期施壓讀數，單挑最多減少安全差 0.025，多人最多減少 0.01，最低保留 0.005。若多名對手同額下注，採其中較保守的讀數；不因另一個無關對手很激進，就降低面對緊手的防守要求。

- 成牌或聽牌須通過賠率安全差才付費繼續。單挑允許高牌按範圍權益抓詐唬；多人池不採這條高牌防守路徑。
- 聽牌包含有自己底牌參與的四張同花，以及五個連續點數窗口中已有四種點數的順子候選，支援 A2345。順子候選至少有一個私有點數未出現在公牌；重複點數不重複計數。河牌全部停止以聽牌作為理由。
- 聽牌並非乾淨出路或堅果保證。仍可能輸給更大同花、葫蘆或其他牌型，由抽樣權益與價格再限制。
- 單挑價值門檻 0.59，多人 0.67，並要求自身成牌；多人權益不足 0.74 不主動加注。面對下注時，價值加注需權益至少 `max(0.73, 賠率 + 0.25)`。
- 轉牌取值門檻額外提高至 0.69；SPR ≤1.2、權益至少 0.76 且已符合價值加注時可推進。

### 持續下注與半詐唬

上一街最後動作是加注、目前單挑、無跟注成本、牌面濕度低於 0.48，才有持續下注機會。空氣牌路徑另要求權益至少 0.24 且尚未到河牌。每街重新評估；被反加後改跟注，就不保留下一街的這個主動權訊號。

詐唬只在單挑、對手仍可棄牌、對手不是跟注站、跟注成本至多底池 25% 時考慮；還需聽牌、同花 A 阻擋牌搭配棄牌傾向，或上述持續下注條件。多副牌停用阻擋牌訊號。愛說謊型基礎頻率 0.32，老實型 0.035；持續下注機會加 0.12，對手棄牌頻率至少 0.30 再加 0.10，總頻率封頂 0.55。

合法化後，詐唬風險不得超過有效籌碼 30% 或跟注後底池 115%，避免最小加注將小詐唬變成被迫拼光籌碼。

### 過牌誘敵與尺寸變化

單挑、強價值牌、無待跟注、非最後行動位置、濕度低於 0.42、SPR >2 時，愛說謊型有 12%、老實型有 24% 機率過牌誘敵。這讓過牌不總是弱牌；若對手下注，再按本街權益與價格判斷，不保證一定過牌再加注。

翻牌基礎尺寸為跟注後底池 40%（乾燥）或 65%（濕潤），轉牌 75%，河牌 55%。乘上隨機 0.85／1.0／1.15；對跟注站再增加 15 個百分點。相同情境價值與詐唬共用尺寸分布，避免單靠大小識破。

一般加注若同時超過有效籌碼 45% 與跟注後底池 150%，權益須至少 0.73；已另行通過短碼／低 SPR 條件的推進不重複受此限制。

## 對手學習與角色個性

公開跟注、棄牌、再加注統計以每手頻率計算、上限為 1；未滿 30 手向預設值收縮，未滿 10 手不貼風格標籤。這些不是「面對下注時的條件機率」，因此不直接當作精確棄牌率計算詐唬 EV。

對已辨識的再加注型放寬再加注範圍；對跟注站停用詐唬並提高取值尺寸；高棄牌頻率增加合理候選牌的詐唬機率。抽樣範圍保留加注者可能持有的聽牌；近期頻繁施壓會增加弱牌權重，避免永遠把進攻當作強成牌。

### 避免一開始全棄、被大注反覆逼退

這次調整針對三個程式層面的保守來源：開池／防守範圍偏窄、範圍加權將加注過度等同強牌、普通跟注也觸發翻牌後的強牌加權。這是程式檢閱的判斷，未經對局重現或測試確認。

- 每位玩家保留最近 8 手（包含當前手）的公開進攻記號；該手任一街有下注／加注就記 1，同手多次加注不重複累加。新牌局記 0，超過 8 手淘汰最舊一筆；重新開始比賽時隨玩家物件重建而清空。
- `pressure_read = clamp((進攻手數 - 1) / 5, 0, 1)`。只有一手進攻不觸發額外適應；最近窗口有 3 手進攻時為 0.4，6 手時達 1。這代表頻繁進攻，不代表已證實詐唬，也不專門針對真人。
- 加注者較弱起手的權重由 0.50 隨讀數升至 0.95；基礎範圍最多向均勻權重混合 55%。翻牌後無成牌／聽牌的權重由 0.35 升至 0.80。調整對手假想範圍後重新估計權益，沒有直接灌高自己的勝率。
- 新增本街進攻記號，換街清空；只有本街真的下注／加注才套用翻牌後的進攻牌型權重。盲注、普通跟注，以及上街加注但本街只過牌，不單憑下注額被視為本街強進攻。
- 適度放寬正常開池與防守門檻，降低持續施壓者帶來的大注額外門檻。價格不合理仍可棄牌；不設定「每手至少一名 AI 跟注」，也不強迫差牌接全下。

預期效果是：正常開局較常有人進池，反覆大注者更可能遇到合理範圍的跟注。仍有全桌剛好弱牌而棄牌的手數；實際入池率、抗大注效果與效能尚未量測。

每位 AI 在建立時抽取固定開池偏好，同種態度也不完全一致。詐唬與誘敵頻率保留態度差異；不根據玩家勝負偷偷改牌或放水。台詞保留既有繁中語氣，避免同一角色連續重複同一句，真假發言仍不是可靠牌力保證。

翻牌後位置只計入仍能行動的座位；莊家已棄牌或全下時，仍從莊家左側順時針排序，避免錯認最後行動者。翻牌前仍使用位置桶，屬簡化範圍。

## 維護位置與限制

| 檔案 | 責任 |
| --- | --- |
| `app/features/ai/systems/ai_decision_system.gd` | 範圍權重、聽牌、四街決策、下注風險與台詞去重。 |
| `app/features/ai/queries/ai_observation_query.gd` | 合法公開觀察、行動位置、統計收縮。 |
| `app/features/ai/models/ai_profile.gd` | 固定個性、上一街動作與上一句發言。 |
| `app/features/match/models/player_state.gd` | 最近 8 手公開進攻記號、本街進攻狀態。 |
| `app/features/match/systems/betting_system.gd` | 合法加注成功後更新進攻記號。 |
| `app/features/match/systems/turn_system.gd` | 換街時重置本街進攻狀態。 |

舊 `seed_street_plan`、`apply_street_plan`、`should_trap`、`should_float` 等輔助函式保留，現行主決策不呼叫。現行主動權僅使用上一街最後動作，不是完整跨街搜尋；`aggression` 等舊參數不直接控制新版決策。

這是啟發式 AI，不是 GTO／精確 EV 求解器。有限加權抽樣仍會波動；聽牌範圍判定增加每次抽樣的運算量，效能尚未量測。有效籌碼以最大可匹配對手為上限，未逐邊池估計權益，短碼多邊池的價格判斷仍可能偏差。未新增測試，也未將舊測試通過紀錄視為本版驗證。
